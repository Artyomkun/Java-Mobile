# DZ_8 — Авторизация пользователя

Приложение демонстрирует экран авторизации для умного дома:
- поле логина (`EditText`)
- поле пароля (`EditText`)
- кнопка авторизации (`Button`)
- сохранение введённых данных при повороте экрана через `onSaveInstanceState()`

## Запуск

```bash
cd src/homework/DZ_8
./gradlew assembleDebug
```

Или откройте проект в Android Studio.
